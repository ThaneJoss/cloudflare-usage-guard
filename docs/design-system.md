# 控制台设计系统

## 设计目标

Cloudflare Usage Guard 不是营销页，也不是带装饰图表的账单复刻。界面遵循四条约束：

1. 先回答“现在最危险的是什么”，再展开全部产品。
2. 只可视化 API 真正提供的数据，不从单个快照推导虚假趋势。
3. 将分析估算、API 计数、下限数据和账单精确值明确分开。
4. 数据源局部失败时保留其余可操作信息，并让过期状态可见。

## 信息架构

```text
身份连接
└── 控制台
    ├── 全局状态栏：LIVE / DEMO / STALE、生成时间、刷新
    ├── 账户态势：最高利用率、风险结论、摘要
    ├── 当前压力信号：前三项真实利用率
    ├── 免费额度雷达：产品筛选、指标和重置时间
    ├── PayGo 明细：账期与精确费用
    └── 数据覆盖：采集器健康和明确的覆盖缺口
```

首屏没有轮播、自动播放或假趋势图。风险环代表所有可比较指标中的最高利用率，压力信号
按同一字段排序，因此视觉优先级可以从数据契约直接复算。

## 视觉语言

基础背景采用深石墨色，面板使用轻微蓝灰层级。Cloudflare 橙只用于主行动、品牌和危险
路径；青色用于在线状态与辅助遥测。颜色、间距、圆角、阴影和字体全部集中在
`src/styles/tokens.css`。

- `--accent`：Cloudflare 橙，主行动和品牌焦点。
- `--cyan`：实时状态、健康数据源和技术标识。
- `--danger`：临界、超限和刷新失败。
- `--muted` / `--faint`：次级元数据；仍需满足正文对比度要求。
- 标题使用紧凑无衬线字族，代码和遥测标签使用等宽字族。

动态宽度只表达真实的利用率或风险压力。装饰网格、光晕和扫描线均标记
`aria-hidden="true"`，不会进入辅助技术的阅读顺序。

## 状态模型

| 状态 | 界面行为 |
| --- | --- |
| 首次连接 | 解释安全边界并要求 HTTPS API Origin |
| 首次加载 | 显示独立骨架页，不闪现连接表单 |
| 成功 | 显示 `LIVE` 或 `DEMO` 与快照生成时间 |
| 后台刷新 | 保留当前内容，按钮和主内容标记忙碌 |
| 刷新失败 | 保留最后成功快照，标记 `STALE` 并提供重试 |
| Access / 网络错误 | 提供新标签页完成 Access 身份授权 |
| API / 契约错误 | 只给对应诊断，不误导用户进入 Access |
| 组件崩溃 | Error Boundary 提供恢复与安全演示入口 |

请求使用序号屏障和 AbortController。较早响应不会覆盖较新的刷新，25 秒超时会归类为
独立错误。浏览器只持久化规范化后的 API Origin，不持久化令牌或响应内容。

## 响应式规则

- 宽屏：风险态势、摘要和信号队列形成控制室式网格。
- 中屏：摘要与产品卡收敛为两列，保持风险优先顺序。
- 窄屏：所有核心状态保留，账单行转换为带 `data-label` 的卡片，不隐藏
  `LIVE` / `DEMO` / `STALE`。
- 交互目标保持至少 44 CSS px；筛选区域允许横向滚动，不缩成不可读的小字。
- 打印样式去除装饰和交互控件，保留数据、时间与口径说明。

## 无障碍约束

- 页面提供跳到主要内容链接。
- 筛选按钮暴露 `aria-pressed`。
- 进度条包含名称、最小值、最大值、当前值和文本值。
- 刷新、错误和空状态使用适当的 live region，不依赖颜色传达结果。
- 表格包含 caption 和列标题；移动端转换后仍保留同一 DOM 语义。
- 图标链接提供产品名称；纯装饰图标从可访问树隐藏。
- 支持 `prefers-reduced-motion`，关闭扫描、旋转和过渡动画。
- 焦点样式使用可见外框，不移除浏览器键盘导航能力。

## 性能约束

当前界面不引入图表运行时、CSS-in-JS 或远程字体。风险环和进度条由 CSS 原生绘制，
图标按 ESM 引入。生产构建：

- 禁止 source map。
- JS gzip 上限 90 KiB。
- CSS gzip 上限 12 KiB。
- hash 静态资源使用一年不可变缓存。
- HTML 和 API 响应不做不可变缓存。

`scripts/check-bundle.mjs` 在 CI 中强制执行预算，依赖升级导致体积回归时会直接失败。

## 组件与文件边界

- `src/App.tsx`：只负责状态路由与页面组合。
- `src/hooks/useUsageData.ts`：连接、刷新、竞态、超时和持久化。
- `src/lib/usage.ts`：运行时契约、筛选、排序和格式化。
- `src/components/`：按页面区块拆分的纯展示组件。
- `src/styles/`：令牌、基础、壳层、控制台和响应式样式。
- `shared/quota-catalog.ts`：前后端共用的额度与产品元数据。
- `worker/src/`：Access 验证、Cloudflare API 客户端和聚合器。

新增产品时必须先补共享目录与来源口径，再接入 Worker 采集器和 UI；不得仅在前端添加
静态进度卡。
